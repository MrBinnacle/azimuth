# Multi-Lens Summary Template

Use when `references/multi-frameworks.md` is loaded.

---

## Template

```markdown
## Multi-Lens Summary

### Core AZIMUTH Verdict
[verdict + one-sentence rationale]

### Lens 1 — [name]
- Finding: ...
- Decision impact: ...

### Lens 2 — [name]
- Finding: ...
- Decision impact: ...

### Lens 3 — [name, optional]
- Finding: ...
- Decision impact: ...

### Synthesis
- Where lenses agree: ...
- Where lenses conflict: ...
- Final reconciliation: ...
- Register / verdict change: ...
```

---

## Use Rules

- Use 2 lenses by default; 3 only in DEEP or user-requested MULTI-LENS.
- Do not let a lens override a launch-blocking operational risk without explaining why.
- If lenses create complexity but no decision change, omit the section.

---

## Provenance

Original AZIMUTH output template for conditional multi-framework synthesis.
