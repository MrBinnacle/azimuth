# Product

## Register

brand

## Users

Decision-owners with real downside: PMs, founders, engineering leads, whoever holds the call. Someone who has authority over a decision that can go wrong and knows it. Not looking for reassurance — looking for the thing they missed.

## Product Purpose

AZIMUTH pressure-tests decisions before commitment. It surfaces the assumption holding everything together, the dependency nobody secured, and the failure mode that's common in decisions like this one but invisible from inside it. The output is a verdict with a rationale — not a risk register with no recommendation.

Success: the user changes the plan before committing, not after.

## Brand Personality

Precise · Unsparing · Adversarial

Adversarial on the user's behalf. Structured to argue against the plan, surface what would have to be true for it to work, and state clearly when those things aren't true. The verdict comes first. The analysis supports it — not the reverse.

## Anti-references

1. **SaaS-cream AI tool** — white/purple gradient, copy that says "unlock" or "supercharge," hero that reassures. Every LLM wrapper launched in 2024. The aesthetic already rejects this; the copy must too.

2. **Dev-bro terminal dump** — all dark-green terminal, GitHub README energy, zero design intent. Functionality without presence. AZIMUTH has both.

3. **Consulting deliverable** — framework-heavy, "dimensions" and "lenses," verdict soft-landed at the end of slide 12. McKinsey lite. AZIMUTH's verdict is the first sentence. The rest is evidence, not preamble.

## Design Principles

1. **Verdict first.** Every surface — hero copy, example output, case study framing — leads with the finding, not the methodology.
2. **Practice what you preach.** A decision-analysis tool that hedges its own copy undermines itself. State things plainly.
3. **Presence without decoration.** The aesthetic should read as precision instrument, not UI exercise. Every element earns its place.
4. **No reassurance.** Do not soften. The Healthcare.gov case study exists because AZIMUTH surfaced five root causes before anyone was willing to name them. That posture extends to the brand surface.
5. **Structural over generic.** Copy that could apply to any tool is copy that doesn't apply to this one. Be specific.

## Accessibility & Inclusion

WCAG 2.1 AA minimum. Reduced-motion media query already implemented in index.html. Keyboard navigation and screen reader semantics required on any interactive elements.
